# RAG Packages

Packages under `rag/` provide RAG (Retrieval-Augmented Generation) tooling that connects Harness agents to external knowledge bases.

## Packages

| Package | Description |
|---|---|
| [`tool-rag`](tool-rag/README.md) | Model-facing `rag_query` tool that queries YiKnowledge via the YiAi RAG API. |
